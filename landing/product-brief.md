## 一、一句话定位

**把纸上的乐谱，变成「跟着音乐自动走」的动态谱。**

用户导入乐谱（钢琴、吉他、贝斯、小提琴、架子鼓……任何乐器的谱子都行）、画线分节、边听音乐边点出每个小节的开始时间，软件就会生成一段**谱面随音乐自动滚动、红色光标线在音符上移动 / 高亮框逐小节跳动**的教学视频（MP4），学生看着视频就能跟练。

---

## 二、产品简介（它能做什么）

RhythmScore 是一款 **macOS 原生桌面应用**，为**音乐教学与练习**而设计。**适用于一切乐器的乐谱**：钢琴、吉他、贝斯、小提琴、架子鼓、管乐、弦乐等——只要是"谱子 + 音频"的场景都能用。核心是一条完整的工作流：

1. **导入乐谱**：支持 PDF / JPG / PNG，可一次拖入多张，自动拼接成一张长图，可调整顺序。
2. **画线分节**：用横线划分行、竖线划分小节，自动编号；支持智能吸附印刷谱面的小节线。
3. **音频对点**：导入伴奏/示范音频，边播放边点击对应小节打时间点；支持反复段落多次打点。
4. **一键成片**：导出 MP4 视频，谱面跟着音乐节奏滚动，配红色光标线或跳框高亮跟随。

## 三、目标用户与痛点（重要：做官网的核心内容）

### 目标用户

- **各类乐器的老师**（钢琴 / 吉他 / 贝斯 / 小提琴 / 架子鼓 / 管弦乐……）与音乐培训机构（核心用户）
- 正在学习任何一种乐器的学生与自学者
- 需要"跟谱演示"的教学场景（课堂大屏、直播、短视频、陪练）

### 痛点一：纸质乐谱不会动，跟练全靠脑子记

- 打印的乐谱静止不动，学生一边听音乐一边低头找"自己看到哪一行了"，频繁走神、重来。
- 老师无法同时兼顾"播放音乐"和"指谱子"。
- **RhythmScore 的答案**：红色光标线在谱上实时移动，音乐到哪，光标就到哪；谱面随音乐自动滚动。学生只要跟着光标演奏，不会丢位置。

### 痛点二：反复段落对点极其繁琐、容易错

- 乐谱中反复记号非常常见（D.S.、跳房子、反复两次）。同一小节要演奏两遍甚至多遍，需要**在同一个位置记多个时间点**，且第二遍要**自动跳回原小节**。
- 手写时间表 + 人工算偏移，又慢又容易错，改一次全乱。
- **RhythmScore 的答案**：同一小节可以打多个时间点（反复段落），播放到第二遍时自动跳回对应小节重新走光标；所有时间点可精确微调（±0.05 秒），随时删除误点，编号自动重排。

### 痛点三：备课耗时，且课后学生拿不到练习材料

- 每节课前要手动准备谱子、录音、计时器，备课两小时、上课五分钟。
- 上完课学生没有任何可带回家的跟练材料，练习效果打折。
- **RhythmScore 的答案**：十分钟完成一份"会动的谱"；导出的 MP4 直接发到学生手机/班级群，课后照常跟练，等于把课堂延长到了家里。

### 痛点四（隐性）：操作复杂的学习成本

- 传统打谱/剪辑软件功能臃肿，学起来要一星期。
- **RhythmScore 的答案**：一条线性工作流（导入→分节→对点→导出），没有多余概念；拿到手几分钟就能完成第一支视频。

## 四、核心优势与亮点（逐一可作官网卖点）

### 1. 会跟音乐的谱（核心卖点）
- 连续模式：红色光标线在小节内随播放匀速移动，顶部有发光圆点，直观指示"现在该演奏到哪"。
- 跳框模式：整个小节高亮成"发光玻璃框"，并预显示下一小节，适合演示重点段落。
- 光标线颜色、粗细、浓度（深浅）全部可调，白天黑夜界面都清晰。
- **谱子类型完全通用**：五线谱、简谱、和弦谱、鼓谱、指法谱……只要是图片/PDF 就能用。

### 2. 反复段落智能处理（差异化卖点）
- 同一小节可多次打点，每个时间点独立编号、独立显示、独立微调。
- 播放/导出时严格遵循打点顺序：反复第二遍自动跳回对应小节，光标从头重走。
- 演奏序号自动排列（如第 2 小节演奏两次 → 显示 2 和 7），也可手动改编号，后续自动顺延。

### 3. 画线分节：智能又省力
- 智能识别谱面印刷小节线，画线时自动吸附对齐。
- 小节自动编号，点击即可修改；多页谱自动拼接成长图，可排序。
- 误操作随时可撤销/删除，不存在"画错了重来"。

### 4. 对点精确到 0.05 秒
- 边听边点，打点即生成时间戳；每个时间点可在弹窗中直接输入秒数/分:秒微调，或 ±0.05 秒步进微调。
- 波形图 + 打点标记，肉眼确认每个点的位置。

### 5. 界面：年轻、干净、专业
- 液态玻璃质感（磨砂 + 光斑），深色/浅色两套主题，**自动跟随系统白天黑夜**。
- 三栏布局（分割乐谱 / 画布 / 音频与导出），操作都在眼前。

### 6. macOS 原生体验
- 原生应用，流畅不卡；支持快捷键（⌘O 打开、⌘S 保存）；项目文件一键保存/打开，自动续接上次工作。

## 五、便携性（官网单独强调）

- **导出即带走**：最终产物是标准 MP4，微信/QQ/网盘随手发，学生手机直接播放，无需安装任何软件。
- **课堂内外通用**：课堂大屏演示用电脑，课后跟练用手机，同一份文件两处用。
- **项目可保存可续**：工作做到一半保存项目，下次打开继续，不丢进度。
- **轻量单机**：全部本地完成，不依赖网络、不注册账号、无隐私上传。
