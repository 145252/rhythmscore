QUICK START

十分钟上手

跟着这四个步骤，把第一张动态谱做出来

1

导入曲谱

打开 RhythmScore，把 PDF / JPG / PNG 曲谱拖进窗口。多张图片或多页 PDF 会自动拼接成一张长谱，可拖动排序。

2

画线分节

用横线标出每一行谱表的上下边界，用竖线切出小节（会自动吸附印刷的小节线）。需要逐拍跟随时，开启拍号细分，在小节内画每拍分线。

3

音频对点

导入伴奏音频，进入对点模式：播放音频，听到一个拍点就点一下对应的小节（或按 回车）。橙色预选框会自动指向下一小节；反复段落同小节多点几次即可。

4

导出成片

在右侧选择连续光标或跳框高亮，调整颜色与浓度，勾选颜色进度、拍点小球，选好比例（单行 / 9:16 / 16:9），一键导出 MP4。

💡 小技巧：画线时开着「自动吸附」，竖线会像磁铁一样贴住印刷的小节线；画错了随时用橡皮擦擦掉，或 ⌘Z 撤销。
FAQ

常见问题

全部支持。钢琴、吉他、贝斯、小提琴、架子鼓、尤克里里……只要是 PDF / 图片形式的谱子（五线谱、简谱、鼓谱、和弦谱）都能用。我们不识别音符，只按你画的线切小节，所以任何谱面都通用。

导出 MP4 视频，支持 1080P（单行 / 16:9 / 9:16 竖屏），高画质编码，可直接发到微信、朋友圈或教学平台。也支持按小节自动切片，方便逐段讲解。

macOS 系统的 Mac（Apple 芯片或 Intel 均可）。双击 DMG 安装即可，无需额外环境。Windows 版正在规划中。

同一小节可以打多个时间点（每遍打一次），播放时会按事件顺序依次走：第一遍走到该小节，第二遍自动跳回再走一遍。演奏序号可在事件面板里自定义微调。
