# RhythmScore 律谱

把 PDF / 图片乐谱，变成跟随音乐自动走动的动态谱。

macOS 桌面应用 · 钢琴 / 吉他 / 鼓 / 小提琴全乐器通用。

## 官网

https://rhythmscore.cn

## 下载

- [RhythmScore v0.4.0（macOS DMG，Apple 芯片 / Intel）](https://github.com/145252/rhythmscore/releases/latest/download/RhythmScore-0.4.0.dmg)

> 打开 DMG 后，把 RhythmScore 拖进「应用程序」即可。首次打开如提示"无法验证开发者"，请在「系统设置 → 隐私与安全性」中点「仍要打开」。
